# Embedded country data

`countries.json` is generated by `go run ./src/countrydata`. The command is for dataset maintenance only; the server embeds the generated JSON and makes no runtime data requests.

## Sources and field provenance

| Fields | Source/version | License and attribution |
|---|---|---|
| Common and official names, ISO alpha-2/alpha-3/numeric codes, capitals, regions, currencies, languages, area, coordinates, borders, top-level domains | [`mledoze/countries`](https://github.com/mledoze/countries), commit `6031f5df137c41c76d180c55a0782185ae3ed05b` | Open Database License 1.0 (ODbL); see [`COPYING-ODbL-1.0.txt`](COPYING-ODbL-1.0.txt) and upstream [sources and credits](https://github.com/mledoze/countries#sources). |
| Population and `population_year` | World Bank World Development Indicators `SP.POP.TOTL`, 2024 observations | CC BY 4.0; attribution: World Bank, World Development Indicators, “Population, total” (indicator SP.POP.TOTL), 2024. See [`COPYING-CC-BY-4.0.txt`](COPYING-CC-BY-4.0.txt) and [indicator metadata](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/SP.POP.TOTL). |
| IANA time zone identifiers | IANA tzdb release `2026e`, `zone1970.tab` | Public domain, as stated in the source file. |
| `flag` | Regional indicator emoji computed from the ISO alpha-2 code | Algorithmically derived; no flag artwork is embedded. |
| `flag_svg_url` | URL formed from the ISO alpha-2 code for the flag-icons assets at [flagcdn.io](https://flagcdn.io/docs/) | Assets are from `flag-icons`, MIT licensed; the application links to these assets and does not download or embed them. |

The mledoze source contains Kosovo (`XK`) in addition to the IDEA.md target of 249 ISO 3166-1 entities. The generator excludes that user-assigned code, resulting in 249 records. Population values are nullable when the World Bank has no 2024 observation for a record; missing data is not fabricated. Some countries have an empty time-zone list when `zone1970.tab` does not associate a distinct post-1970 time zone.

The generated database is distributed under ODbL 1.0. The World Bank population values retain their CC BY 4.0 attribution requirement. The application source remains MIT licensed.

## Updating

Run `go run ./src/countrydata` to download the pinned sources and regenerate `countries.json`. To reproduce from already downloaded source files, pass `-countries`, `-population`, and `-tzdb` file paths. Review the resulting diff, record source-version changes here, and verify the 249-record count before release.
