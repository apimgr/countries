REST API

All endpoints are read-only and require no authentication.

OpenAPI JSON specification

Countries

  • GET {{.APIBasePath}}/countries — list records
  • GET {{.APIBasePath}}/countries/{code} — look up a country code
  • GET {{.APIBasePath}}/countries/search?q={query} — search country data

Coordinates

  • GET {{.APIBasePath}}/coordinates?lat={lat}&lon={lon} — nearest representative coordinate
  • GET {{.APIBasePath}}/nearby?lat={lat}&lon={lon}&radius={km} — records within a radius

Metadata

  • GET {{.APIBasePath}}/stats — record count and build version
  • GET {{.APIBasePath}}/server/healthz — health check
